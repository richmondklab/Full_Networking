# 🌐 Full Networking

Dépôt de ressources réseau : notes de cours, travaux pratiques (Cisco Packet Tracer) et projets, organisés en parcours progressif — des fondamentaux réseau jusqu'à la sécurité et l'automatisation réseau.

## 📖 À propos

Ce dépôt regroupe du contenu pédagogique et pratique autour des réseaux informatiques (CCNA et au-delà) : concepts théoriques, configurations réelles, labs Packet Tracer et scripts d'automatisation. L'objectif est d'offrir une base claire et réutilisable, aussi bien pour un débutant qui découvre les réseaux que pour quelqu'un qui prépare ses certifications.

## 📂 Structure du dépôt

| Dossier | Contenu |
|---|---|
| `00-Fondamentaux/` | Modèle OSI/TCP-IP, adressage IP, subnetting |
| `01-CCNA1-Introduction/` | Notes et labs — introduction aux réseaux |
| `02-CCNA2-Switching-Routing/` | Notes, labs et cas de troubleshooting |
| `03-CCNA3-Enterprise-Network/` | Réseaux d'entreprise, sécurité et automatisation |
| `04-Securite-Reseau/` | ACL, pare-feu, VPN/IPSec, hardening |
| `05-Protocoles-Avances/` | BGP, OSPF avancé, MPLS, QoS |
| `06-Automatisation-Reseau/` | Scripts Python (Netmiko), Ansible |
| `07-Labs-Projets/` | Projets pratiques et topologies complètes |
| `08-Certifications/` | Ressources et roadmap de certification |

## 🛠️ Compétences couvertes

Routing & Switching · VLAN · ACL · VPN · OSPF/BGP · Sécurité réseau · Automatisation (Python/Ansible) · Packet Tracer

## 🚀 Utilisation

Chaque dossier est autonome et contient :
- des notes en Markdown,
- les fichiers Packet Tracer (`.pkt`) associés,
- des explications de topologie quand nécessaire.

Clone le dépôt et navigue directement dans le dossier qui t'intéresse :

```bash
git clone https://github.com/richmondklab/Go-CCNA.git
```
